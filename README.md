# 💣 Сапёр

Классический «Сапёр» в стиле старого Windows — с лёгкой, средней, сложной и своей сложностью, а также светлой и тёмной темой.

## 🎮 Играть

**[▶ Открыть игру](https://pxdxx.github.io/Miner/)**

> Замени `username` и `repo` в ссылке выше на свой логин GitHub и название репозитория (или включи GitHub Pages в настройках репозитория: *Settings → Pages → Source: main*).

## ✨ Возможности

- 🟢 Уровни сложности: лёгкий, средний, сложный, свой
- 🌗 Переключение светлой и тёмной темы
- 🖱️ Классическая механика Сапёра прямо в браузере

## 🚀 Локальный запуск

Просто открой `index.html` в браузере - никаких зависимостей не требуется.
